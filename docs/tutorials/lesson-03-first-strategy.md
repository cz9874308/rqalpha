## 3.1 认识示例策略

### 打开策略文件

首先，让我们看看"买入持有"策略长什么样。

找到并打开 `examples/buy_and_hold.py` 文件：

```python
def init(context):
    # 在 context 中保存要操作的股票
    context.stock = "000001.XSHE"  # 平安银行
    
def handle_bar(context, bar_dict):
    # 获取当前持仓
    cur_position = get_position(context.stock).quantity
    
    # 如果没有持仓，就买入
    if cur_position == 0:
        # 用全部资金买入
        order_value(context.stock, context.portfolio.cash)
```

### 策略逻辑解读

```
┌─────────────────────────────────────────────────────────────┐
│                    买入持有策略逻辑                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   1. 策略启动时，设定目标股票为"平安银行"                     │
│                    ↓                                        │
│   2. 每天检查是否已经持有该股票                               │
│                    ↓                                        │
│   3. 如果没有持仓，用全部资金买入                             │
│                    ↓                                        │
│   4. 买入后一直持有，不做任何操作                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

> 💡 **买入持有**（Buy and Hold）是最简单的投资策略之一，就是买入后长期持有不动。

## 3.2 运行策略

### 基础运行命令

打开终端，进入 examples 目录，执行：

```bash
rqalpha run -f buy_and_hold.py -s 2020-01-01 -e 2020-12-31 --account stock 100000
```

### 参数详解

让我们逐个理解这些参数：

| 参数 | 含义 | 示例 |
|------|------|------|
| `-f` | 策略文件路径 | `buy_and_hold.py` |
| `-s` | 回测开始日期 | `2020-01-01` |
| `-e` | 回测结束日期 | `2020-12-31` |
| `--account stock` | 股票账户初始资金 | `100000`（10万元） |

### 完整参数图解

```
rqalpha run -f buy_and_hold.py -s 2020-01-01 -e 2020-12-31 --account stock 100000
             │                  │              │             │
             │                  │              │             └── 初始资金10万
             │                  │              └── 结束日期
             │                  └── 开始日期
             └── 策略文件
```

## 3.3 理解回测输出

运行后，你会看到类似这样的输出：

```
                           回测摘要
═══════════════════════════════════════════════════════════════
策略名称                                          buy_and_hold
起始日期                                          2020-01-02
结束日期                                          2020-12-31
运行类型                                             回测
─────────────────────────────────────────────────────────────────
               收益指标
─────────────────────────────────────────────────────────────────
年化收益率                                           25.50%
累计收益率                                           24.30%
基准年化收益率                                       27.21%
基准累计收益率                                       26.85%
─────────────────────────────────────────────────────────────────
               风险指标
─────────────────────────────────────────────────────────────────
最大回撤                                             15.30%
夏普比率                                              1.25
信息比率                                             -0.12
年化波动率                                           20.50%
```

### 关键指标解释

#### 收益指标

| 指标 | 含义 | 怎么理解 |
|------|------|----------|
| **年化收益率** | 折算成一年的收益率 | 25% = 100万变成125万 |
| **累计收益率** | 整个回测期间的总收益 | 回测期间赚了多少 |
| **基准收益率** | 对比指数的收益 | 用来比较策略好坏 |

#### 风险指标

| 指标 | 含义 | 怎么理解 |
|------|------|----------|
| **最大回撤** | 从最高点跌到最低点的幅度 | 最坏情况会亏多少 |
| **夏普比率** | 风险调整后的收益 | >1 较好，>2 优秀 |
| **年化波动率** | 收益的波动程度 | 越低越稳定 |

### 通俗理解

```
假设你有 10 万本金，回测一年：

年化收益率 25%  →  一年能赚 2.5 万
最大回撤 15%    →  最多可能亏 1.5 万
夏普比率 1.25   →  风险收益比还不错
```

## 3.4 查看收益图表

数字看起来比较抽象，让我们用图表来直观展示：

### 添加 --plot 参数

```bash

```

运行后会弹出一个图表窗口：

```

│                     收益曲线图                               │
│                                                             │
│   📈 蓝线：策略收益曲线                                       │
│   📊 灰线：基准（沪深300）收益曲线                            │
│   📉 下方：每日收益柱状图                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 图表解读

| 区域 | 内容 | 含义 |
|------|------|------|
| 上半部分 | 收益曲线 | 蓝线是你的策略，灰线是基准 |
| 下半部分 | 每日收益 | 每天赚了还是亏了 |
| 红色区域 | 回撤 | 从高点下跌的幅度 |

## 3.5 保存回测结果

### 保存图表

```bash
rqalpha run -f buy_and_hold.py -s 2020-01-01 -e 2020-12-31 --account stock 100000 --plot-save result.png
```

图表会保存为 `result.png` 文件。

### 保存详细数据

```bash
rqalpha run -f buy_and_hold.py -s 2020-01-01 -e 2020-12-31 --account stock 100000 -o result.pkl
```

`-o` 参数会把所有回测数据保存到 `result.pkl` 文件。

### 读取保存的数据

```python
import pandas as pd

# 读取回测结果
result = pd.read_pickle('result.pkl')

# 查看包含哪些内容
print(result.keys())
# ['summary', 'stock_portfolios', 'trades', ...]

# 查看回测摘要
print(result['summary'])

# 查看每日净值
print(result['stock_portfolios'])
```

## 3.6 更多运行参数

### 常用参数表

| 参数 | 作用 | 示例 |
|------|------|------|
| `-f` | 策略文件 | `-f my_strategy.py` |
| `-s` | 开始日期 | `-s 2020-01-01` |
| `-e` | 结束日期 | `-e 2020-12-31` |
| `--account stock` | 股票账户资金 | `--account stock 100000` |
| `--account future` | 期货账户资金 | `--account future 100000` |
| `--benchmark` 或 `-bm` | 基准指数 | `-bm 000300.XSHG` |
| `--plot` 或 `-p` | 显示图表 | `--plot` |
| `--plot-save` | 保存图表 | `--plot-save chart.png` |
| `-o` | 保存结果 | `-o result.pkl` |
| `--progress` | 显示进度条 | `--progress` |

### 完整命令示例

```bash
rqalpha run \
  -f buy_and_hold.py \
  -s 2020-01-01 \
  -e 2020-12-31 \
  --account stock 100000 \
  --benchmark 000300.XSHG \
  --plot \
  --progress \
  -o result.pkl
```

## 📝 知识检查

### 基础问题

1. `-s` 和 `-e` 参数分别代表什么？
2. 如何让回测显示收益图表？
3. 夏普比率大于 1 意味着什么？

### 思考题

1. 为什么同一个策略在不同年份收益差别很大？
2. "买入持有"策略有什么优缺点？

<details>
<summary>💡 点击查看答案</summary>

**基础问题：**
1. `-s` 是开始日期（start），`-e` 是结束日期（end）
2. 添加 `--plot` 或 `-p` 参数
3. 夏普比率 > 1 表示策略的风险调整后收益较好

**思考题：**
1. 股市不同年份涨跌不同，同一策略会有不同表现。这也说明历史回测不能保证未来收益。
2. 优点：简单省心、交易成本低、长期可能跑赢大多数人
   缺点：遇到熊市回撤大、无法规避风险、需要长期持有

</details>
