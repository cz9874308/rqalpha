## 1.1 什么是量化交易？

### 通俗解释

想象一下，你是一位股票投资者：

**传统投资方式**（手动驾驶 🚗）：
- 每天盯盘看股票
- 凭感觉和经验决定买卖
- 情绪容易影响决策
- 时间精力有限

**量化交易方式**（自动驾驶 🚀）：
- 用程序自动监控市场
- 按照预设规则自动交易
- 不受情绪影响
- 24小时不间断运行

> 💡 **一句话总结**：量化交易就是用计算机程序代替人来做投资决策和执行交易。

### 量化交易的优势

| 优势 | 说明 |
|------|------|
| 🎯 纪律性强 | 严格按照规则执行，不受情绪干扰 |
| ⚡ 速度快 | 毫秒级响应，抓住稍纵即逝的机会 |
| 📊 数据驱动 | 基于大量历史数据做决策 |
| 🔄 可回测 | 在历史数据上验证策略效果 |
| 📈 可优化 | 通过参数调优提升收益 |

### 量化交易的基本流程

```
1. 策略构思        "当股价上涨突破20日均线时买入"
       ↓
2. 编写代码        把想法转化成程序代码
       ↓
3. 历史回测        用历史数据验证策略效果
       ↓
4. 优化调整        根据回测结果改进策略
       ↓
5. 模拟交易        用实时数据模拟运行
       ↓
6. 实盘交易        用真金白银运行策略
```

## 1.2 RQAlpha 是什么？

### 一句话定义

> **RQAlpha** 是一个开源的 Python 量化交易回测框架，由米筐科技开发和维护。

翻译成人话：
- **开源**：免费使用，代码公开
- **Python**：用 Python 语言编写和使用
- **量化交易**：支持股票、期货等多种交易品种
- **回测框架**：可以用历史数据测试你的交易策略

## 1.3 为什么选择 RQAlpha？

### 核心优势

#### 1️⃣ 易于使用

```bash
# 一行命令运行策略
rqalpha run -f strategy.py -s 2020-01-01 -e 2020-12-31
```

不需要配置复杂的环境，安装即可使用。

#### 2️⃣ 免费开源

- 代码完全开源，托管在 GitHub
- 免费使用，无需付费
- 可以自由修改和扩展

#### 3️⃣ 文档完善

- 详细的 API 文档
- 丰富的策略示例
- 活跃的社区支持

#### 4️⃣ 灵活可扩展

通过 **Mod（模块）** 机制，可以轻松扩展功能：
- 对接不同数据源
- 添加自定义指标
- 实现实盘交易

### 和其他框架的比较

| 特性 | RQAlpha | 其他框架 |
|------|:-------:|:--------:|
| 开源免费 | ✅ | 部分收费 |

│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐       │

### 核心概念预览

| 概念 | 说明 | 类比 |
|------|------|------|
| **策略 (Strategy)** | 你编写的交易逻辑 | 驾驶员的开车方式 |
| **回测 (Backtest)** | 用历史数据测试策略 | 在模拟器上练习开车 |
| **事件 (Event)** | 触发策略执行的信号 | 交通信号灯 |
| **订单 (Order)** | 买入/卖出的指令 | 下达的行车指令 |
| **持仓 (Position)** | 当前持有的证券 | 车上装载的货物 |
| **账户 (Account)** | 资金和持仓的集合 | 你的银行账户 |

## 📝 知识检查

### 基础问题

1. 量化交易和传统投资的主要区别是什么？
2. RQAlpha 的核心功能有哪些？
3. "回测"是什么意思？

### 思考题

1. 量化交易有没有缺点？你能想到哪些？
2. 为什么在实盘交易之前要先做回测？

<details>
<summary>💡 点击查看参考答案</summary>

**基础问题答案：**

1. 量化交易用计算机程序自动执行交易决策，而传统投资依赖人工判断。量化交易更客观、更快速、可回测。

2. RQAlpha 的核心功能包括：数据获取、策略编写、历史回测、结果分析、模拟交易、实盘对接。

3. 回测是用历史市场数据来模拟运行交易策略，验证策略在过去的表现如何。

**思考题参考：**

1. 量化交易的缺点包括：
   - 历史表现不代表未来（过拟合风险）
   - 需要编程能力
   - 市场极端情况可能失效
   - 同类策略拥挤可能导致失效

2. 回测可以：
   - 验证策略逻辑是否正确
   - 评估策略的收益和风险
   - 发现潜在问题
   - 避免用真金白银试错

</details>
